# Demonstração do PromptRoast

Abra esta pasta como projeto em uma nova conversa do Codex. A integração global instalada contém a skill e a regra para avaliar prompts elegíveis. Experimente um pedido com objetivo e critérios; em seguida, peça `$prompt-roast score`. Para apagar as notas da sessão, use `$prompt-roast reset`. Veja a documentação principal um diretório acima para mais comandos e informações de instalação.
